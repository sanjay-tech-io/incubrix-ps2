# Submission evidence

One row per item, ready to copy into the Excel Submission Form. Columns: item | Yes / Partial / No | evidence | what is not covered.

How to read it
- **Item wording** comes from `docs/REQUIREMENTS.md`, my checklist of the brief. It is a paraphrase, not the brief itself. Compare the wording with the original brief before pasting it into the form.
- **Yes** means I ran it and the evidence file shows it, within the limit written in the last column. **Partial** means part of it ran, or it ran only on synthetic or mocked data. **No** means it was not built or not run.
- Evidence paths are relative to the repository root. `S01`..`S53` are `scenarios/sNN_*.yaml` (mock transcript, generated video, run by `docker compose run --rm tests`; result: `docs/raw/m5b_scenarios_run.txt`, 50 of 50). `Session NN` is `sessions/NN_*.yaml` on the real recording `media/test_single.mp4` (real ASR; result: `test-pack/real/batch_720p_m5e/summary.json`, 33 of 38 pass).
- The scenarios test editing, not speech recognition. I list them as evidence for behaviour, never for recognition quality.
- Media is not in git (`SOURCES.md`). Rendered videos are git-ignored; they are on this VM under `test-pack/` and downloadable read-only at `https://34.93.140.79.sslip.io/pack/` (HTTP basic auth; credentials are given to the reviewer separately). A file at `test-pack/<path>` is at `https://34.93.140.79.sslip.io/pack/<path>`. Every video link below uses it. How the folder is built and tested: `test-pack/INDEX.md` section 0, `docs/raw/m6b_pack_access.txt`.
- No GitHub Actions run is recorded in this repository. No result has been supplied to me, and the GitHub repository is not readable without login from this VM (the public API answers 404), so I could not look. The CI rows stay Partial until a run is recorded. At the final check (2026-10-24) `origin/main` and the local `main` were at the same commit (`159d94e`); the final-check commits that follow are local and not pushed.
